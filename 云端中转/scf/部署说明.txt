麦田守望 · 成绩/资料「直接提交」中转 · 部署说明
（腾讯云函数 SCF + API 网关，一次配好长期用，约 15 分钟；不用备案）

════════════════════════════════════════════════════════════════
一、准备
  1. 腾讯云账号 + 实名认证（微信扫码登录 → 个人实名，1 分钟）
  2. 一个 GitHub 写权限令牌（Contents: Read and write）—— 就用队长版同步的那个，可复用
     （令牌只填在云函数里，绝不放进网页、不放进仓库）
════════════════════════════════════════════════════════════════
二、建云函数（8 步）
  1. 打开 https://console.cloud.tencent.com/scf →「函数服务」→ 新建
  2. 选「从头开始」；函数名 maitian-relay；地域选广州或上海
  3. 运行环境选 Node.js 18（或 20）
  4. 提交方法选「在线编辑」，把 云端中转/scf/index.js 的内容整个粘进去（覆盖默认代码）
  5. 「函数配置」→ 环境变量，加这 5 个：
       GH_TOKEN    你的写权限令牌
       GH_OWNER    zl4639574-bit
       GH_REPO     maitian-running
       GH_BRANCH   master
       TEAM_CODE   队伍口令（自己起一个，比如 maitian-2017，告诉队员的那串）
     顺手把「超时时间」改成 20 秒，内存 128MB 就够
  6. 保存后 →「触发管理」→ 新建触发器 → 触发方式选「API 网关」→ 创建
     （如提示创建 API 网关服务，选「新建」即可）→ 得到一个访问地址，形如：
       https://service-xxxxxxxx-1234567890.gz.apigw.tencentcs.com/release/maitian-relay
  7. 记下这个地址（就是我们说的"收件服务地址"）
  8. 自测：浏览器直接打开它 → 应该显示 {"ok":false,"error":"只接受 POST"}（说明通了）
════════════════════════════════════════════════════════════════
三、把地址填进队长版
  队长版 →「数据管理」→「同步」→ 拉到底「收件中转（队员直接提交用）」：
    · 收件服务地址 = 上面那个地址
    · 队伍口令     = TEAM_CODE（比如 maitian-2017）
    → 点「测试收件服务」→ 出现"收件服务正常 ✅"就成功了
    → 点「保存收件设置」→ 再点「同步我的修改到线上」（队员端才会拿到这个配置）
  之后队员端的收集页就会出现「⚡ 直接提交给队长（不用发微信）」
════════════════════════════════════════════════════════════════
四、队员怎么用
  打开 https://zl4639574-bit.github.io/maitian-running/report/
    → 填成绩 / 完善资料 → 点「⚡ 直接提交给队长」→ 提示"已提交给队长"就完成了
    （不用复制、不用发微信、不用加你微信；手机普通浏览器直接能用）
════════════════════════════════════════════════════════════════
五、你（队长）怎么收
  队长版 →「上传成绩」→「① 收件箱」→ 点「读取收件箱」
    · 每条显示：是"资料"还是"成绩"、谁提交的、内容摘要、时间
    · 点「接收」：资料 → 写进名册（照片自动传成头像）；成绩 → 进「我录入的成绩」，接着并进某场比赛
    · 接收完，收件箱里那条会自动从仓库删掉（不留垃圾）；点「丢弃」也一样删
    · 收完记得去「数据管理 → 同步」把改动同步上线
════════════════════════════════════════════════════════════════
六、费用与安全
  · 费用：云函数每月有免费额度（几万次调用），你们这点量基本 0 元；API 网关按量，费用极低
  · 安全措施（代码里已经写好）：
      - 只能写 data/inbox/ 下的新文件，别的路径一律拒绝，也**不能覆盖**已有文件
      - 必须带对队伍口令，口令不对直接拒绝
      - 同一 IP 每分钟最多 5 次；单次内容 ≤ 200KB；字段做白名单和长度校验
      - 令牌只存在云函数的"环境变量"里 —— 不在网页、不在仓库、不在聊天里
  · 想临时关掉：把 TEAM_CODE 改掉（或删掉触发器）；队员端会自动退回「📤 发给队长（微信）」
════════════════════════════════════════════════════════════════
七、出问题怎么查
  · 测试报"连不上收件服务"：确认函数创建成功、触发器地址是否和填的一致；看云函数「日志」
  · 报"中转的令牌没权限写仓库"：GH_TOKEN 的 Contents 要选 Read and write（和队长版同一套要求）
  · 报"连不上 GitHub"：换个地域（广州/上海/北京）再试；代码里已自动重试 3 次
  · 队员端看不到「⚡ 直接提交」按钮：队长版「保存收件设置」后，必须再点一次
    「同步我的修改到线上」（配置是通过 overrides.js 同步给所有队员端的）
  · 收件箱是空的：队员是不是点了「📤 发给队长（微信）」那条路（那个不发到收件箱，会直接发你微信）
════════════════════════════════════════════════════════════════
附：不想用腾讯云了怎么办
  · 队员端自动退回微信分享/复制那条路，功能不受影响；
  · 想换成别的服务（自己的服务器、别的云函数）也行：只要实现同一个接口 ——
      POST JSON {code, type:'scores'|'member', payload} → 成功返回 {"ok":true,"id":"..."}
    把新地址填回队长版即可，网页代码不用改。
