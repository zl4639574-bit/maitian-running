方案 A（腾讯云 · 按量 · 推荐）：云函数 SCF + 函数 URL     约 10 分钟
────────────────────────────────────────────────────────────────
  1. 打开 https://console.cloud.tencent.com/scf →「函数服务」→ 新建 → 选「从头开始」
     函数名 maitian-relay；地域选广州 / 上海 / 北京；运行环境 Node.js 18（或 20）
  2. 提交方法选「在线编辑」→ 打开「中转代码（复制到云函数）.txt」全选复制 →
     粘进在线编辑器（先把默认代码全选删掉）→ 保存 / 部署
  3. 「函数配置」→ 环境变量，加这 5 个：
       GH_TOKEN   你的写权限令牌（Contents: Read and write）
       GH_OWNER   zl4639574-bit
       GH_REPO    maitian-running
       GH_BRANCH  master
       TEAM_CODE  队伍口令（自己起一个，例如 maitian-2017）
     顺手把「超时时间」改成 20 秒，内存 128MB 足够
  4. 「触发管理」→ 新建触发器 → 找 **「函数 URL」**：
       · 认证方式：选「无认证」（队员端没有腾讯云身份，必须免认证）
       · 请求方法：POST（能多选就把 OPTIONS 也勾上）
       · 若控制台有「跨域 / CORS」开关 → 打开；
         没有也没关系：队员端网页故意用 text/plain 提交（属于"简单请求"），不会触发浏览器预检
       · 如果这里还看得到「API 网关」也行，用哪个都可以
  5. 保存后得到形如 https://<一串ID>.tencentscf.com 的访问地址
     自测：浏览器直接打开它 → 应显示 {"ok":false,"error":"只接受 POST"}（说明通了）
  6. 把地址 + 队伍口令填进队长版：「数据管理」→「同步」→「收件中转」
     →「测试收件服务」（显示"收件服务正常 ✅"）→「保存收件设置」→「同步我的修改到线上」
  7. 之后队员端收集页出现「⚡ 直接提交给队长」；你在「上传成绩 → ① 收件箱」一键接收

  费用与告警：新用户前 3 个月有免费试用额度，之后按量计费（调用次数 + 资源使用量），
  你们的量一年大约几块钱。建议去「费用中心 → 预算与告警」设一条"月消费超过 ¥1 就发短信"，
  万一被人刷也第一时间知道。
  补充：第 4 步「触发管理」里**找不到「函数 URL」**怎么办？
    · 原因：腾讯云的「函数 URL」只在**「Web 函数」**类型下提供；事件函数的 HTTP 入口
      原本就是已下线的「API 网关触发器」。所以你建事件函数时看不到它是正常的。
    · 做法一（推荐）：重新新建一个函数，**创建时函数类型选「Web 函数」**
      （有的版本叫"Web 应用"），运行环境 Node.js 18 → 粘同一份代码 →
      在**函数详情页**（不是触发管理）能看到「函数URL / 访问地址」，形如
      https://xxxx.yyy.tencentscf.com → 认证方式选「无认证」→ 用这个地址即可。
      我们这份代码已经兼容 Web 函数的事件格式（body/httpMethod/headers/isBase64Encoded），
      返回值也是标准 {statusCode, headers, body}，不用改。
    · 关于函数 URL 页面那几句提示怎么理解（照这个配就行）：
        1)「URL 仅供测试使用，生产环境请绑定自定义域名」= 腾讯云的标准免责措辞（不承诺 SLA、
           可能限流）。咱们是队内小工具，完全够用；**不需要绑域名**（绑域名还要备案）。
           而且就算它哪天不灵了，队员端会自动退回「📤 发给队长（微信）」，其他功能不受影响。
        2)「可以选择云 CAM 授权」→ **千万别选 CAM 授权**，要选 **「无认证」**！
           因为队员是在浏览器里提交的，没有腾讯云身份；选了 CAM 会直接 403。
           安全靠我们代码里自带的那套（队伍口令 + 同 IP 每分钟 5 次 + 只写 data/inbox/
           + 只能新增不能覆盖 + 单次 ≤200KB）—— 这正是它说的"在函数中实现自己的授权逻辑"。
        3)「一个版本/别名最多一个函数 URL」→ 我们只要一个，没问题。
        4) 如果页面让你填「请求路径」（例如 /submit），地址就会带上这个路径；
           填进队长版「收件中转」时**把完整地址原样复制**（含 /submit）。
        5) 请求方法能勾就勾 POST（能一起勾 OPTIONS 更好；我们的队员端用 text/plain 提交，
           属于"简单请求"，即使不转发 OPTIONS 也不会被浏览器预检挡住）。
        6) 「强制下载（content-disposition: attachment）」这条**不影响我们的提交**：
           · 它只影响"**用浏览器直接打开这个地址**"的显示方式（变成下载文件）；
           · 队员端是网页里的 **fetch() 请求**（程序读返回内容），不受这个头影响，照样能提交、能拿到结果；
           · 所以自测方式改成：浏览器打开地址 → 会下载一个文件 → 打开那个文件看内容，
             里面写 {"ok":false,"error":"只接受 POST"} 就说明函数通了；
             或者干脆跳过自测，直接用队长版「测试收件服务」验证（那一步和队员端一模一样，最准）。
           · 想彻底去掉这个头 = 绑自定义域名（要域名 + 备案），**没必要**。
        7) 如果创建函数 URL 时能看到「跨域 / CORS」配置 → **允许来源填 ***（这样浏览器端一定通）。
           我们的代码也会返回 Access-Control-Allow-Origin: *，两边都覆盖更稳。
        8) 万一函数 URL 因为平台策略把我们的响应头剥掉了（前端会报跨域失败）：
           队员端会**自动退回**「📤 发给队长（微信）/复制」并提示，数据一条都不会丢 —— 可以先这么用着。
    · 做法二：若你的账号能在 https://console.cloud.tencent.com/apigateway 正常使用 API 网关，
      可以**在 API 网关控制台自己建**：新建 API → 路径 /submit → 后端类型"云函数"→ 选中
      maitian-relay → 发布 → 用网关地址。这样不依赖 SCF 的触发器入口。
    · 做法三（最省事，5 分钟）：换阿里云函数计算 FC —— 创建函数时直接勾选「HTTP 触发器」，
      认证方式"无需认证"、方法 POST，拿到 https://xxx.cn-hangzhou.fcapp.run 就行。
      **代码一个字不用改**，费用更便宜（首次开通每月 15 万 CU 给 3 个周期，之后约 ¥0.1~0.3/月）。
    · 三条路随便哪条，最后都是把地址填进队长版「数据管理 → 同步 → 收件中转」→ 测试 → 保存 → 同步。

安全设计（代码里已写好，所有平台通用）
  · 只能写 data/inbox/ 下的**新文件**；不带 sha ⇒ 覆盖不了已有文件（同名会被 GitHub 拒掉）
  · 必须口令正确；同一 IP 每分钟最多 5 次；单次 ≤200KB（照片 ≤150KB）
  · 字段白名单 + 长度上限 + 姓名格式校验
  · 令牌只存在云函数的"环境变量"里 —— 不在网页、不在仓库、不在聊天
  · 想临时关掉：改 TEAM_CODE（或删触发器/路径）；队员端会自动退回「📤 发给队长（微信）」

排错
  · 打开函数 URL 显示别的错误：确认触发器认证方式是"无认证"、方法含 POST
  · 队长版「测试收件服务」报"连不上"：地址是否完整（有的带 /submit 等路径）、是否 HTTPS
  · 队员提交失败但测试能过：看云函数「日志」，多半是令牌权限（Contents 要 Read and write）
  · 报"连不上 GitHub"：换地域再试（广州/上海/北京）；代码里已自动重试 3 次
  · 队员端看不到 ⚡ 按钮：队长版「保存收件设置」后必须再点一次「同步我的修改到线上」
  · 跨域报错（CORS）：确认队员端用的是最新版页面（Ctrl+F5 刷新一次）
