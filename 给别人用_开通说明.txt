给别的队长开通（多人一起维护数据）
================================================================

网址（都一样，谁都能打开，写权限靠各自的令牌）
  展示版  https://zl4639574-bit.github.io/maitian-running/
  队长版  https://zl4639574-bit.github.io/maitian-running/captain/
  说明书  https://zl4639574-bit.github.io/maitian-running/guide.txt

为什么这样做：
  · 数据 = 仓库里的数据文件，读写走 api.github.com（国内直连可用，不用 VPN）
  · 谁都能打开队长版看，但只有"有令牌"的人能改并同步到线上
  · 每人用自己的 GitHub 账号建令牌 → 提交记录里能看出是谁改的 → 你随时能单独撤销某个人

────────────────────────────────────────
【第一步】你（仓库主人）先把他加成协作者
────────────────────────────────────────
  1. 电脑打开（要能访问 github.com，国内时通时断，趁通的时候做）：
     https://github.com/zl4639574-bit/maitian-running
  2. 右上 Settings → 左侧 Collaborators and teams（协作者）→ Add people
  3. 输入他的 GitHub 用户名 → Add → 邀请发出
  4. 让他在自己的 GitHub 通知/邮件里点 Accept（必须他本人同意，你代替不了）

  ⚠️ 这一步不能省：精细令牌只能勾"你有权限的仓库"。没加协作者，他建令牌时
     根本选不到 maitian-running，同步会报"仓库名/分支名不对或没有权限"。

────────────────────────────────────────
【第二步】他建自己的精细令牌（Fine-grained token）
────────────────────────────────────────
  1. 用他自己的 GitHub 账号登录 → 右上头像 → Settings
  2. 左侧最下面 Developer settings
  3. Personal access tokens → Fine-grained tokens → Generate new token
  4. 填写：
        Token name     ：maitian-captain（随便起，能认出来就行）
        Expiration     ：90 days 或自定义（到期后他会看到 401，重建一个即可）
        Resource owner ：他自己的账号
        Repository access：选 Only select repositories
                           → 只勾 zl4639574-bit/maitian-running
  5. 下面的 Permissions → Repository permissions → 找到 Contents
        改成 Read and write（其余全部保持 No access）
  6. Generate token → 复制那串 github_pat_...（只显示一次！丢了就重新生成）

  小提示：队长版「数据管理 → 同步」里有个「一键打开建令牌页面（权限已勾好）」按钮，
          点了会直接跳到 GitHub 建令牌页，省得自己找菜单。

────────────────────────────────────────
【第三步】他在自己的手机/电脑上用队长版
────────────────────────────────────────
  1. 打开队长版网址（手机浏览器就行，不用 VPN；建议加到主屏幕）
  2. 数据管理 → 同步（面板里预填好了：用户名 zl4639574-bit / 仓库 maitian-running / 分支 master）
  3. 把刚才复制的令牌粘进去 → 保存到这台设备
  4. 点「测试同步」，约 1 分钟看到 ✅ 就通了；以后他改完数据点「同步」即可上线
  5. 换设备：在新设备上再粘一次令牌（令牌只存在各自设备的浏览器里）

────────────────────────────────────────
【你（主队长）怎么管理他们】
────────────────────────────────────────
  · 看谁改的：仓库的提交记录（Commits）里，作者就是改动那个人的 GitHub 账号
  · 撤销某人的权限：仓库 Settings → Collaborators 里移除他（或让他自己删掉令牌）
  · 令牌到期/丢失：让他按第二步重新生成一个，重新粘一次即可（旧的自动作废）

────────────────────────────────────────
【几条安全规矩（务必要说清）】
────────────────────────────────────────
  · 令牌只存在自己设备的浏览器里，绝不写进仓库文件、说明书、群聊、截图
  · 不要把你的令牌给别人用（那样提交记录显示的都是你，出事也说不清）
  · 别使用"经典令牌 ghp_..."那种（权限覆盖你账号下所有仓库，太大）
  · 手机上别用无痕窗口（关掉窗口令牌就没了）
  · 两个人同时改同一块数据时，后保存的会覆盖先保存的 → 改之前先刷新一次页面，
    改完尽快点同步；重要的批量修改（比如改身份）尽量一个人做

────────────────────────────────────────
【常见报错对照表】
────────────────────────────────────────
  401 令牌无效或已过期         → 重新生成一个令牌，重新粘
  403 权限不够                → 令牌的 Contents 要选 Read and write
  404 仓库名/分支名不对或无权限 → 常见于"还没被加为协作者"；也检查 用户名/仓库名/分支
  409 文件被别处改过            → 等 10 秒再点一次同步
  同步成功但网页看不到          → GitHub Pages 有 30~90 秒缓存，等 1 分钟刷新即可
