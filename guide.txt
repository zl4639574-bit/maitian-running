【零】怎么打开（电脑 / 手机）—— 先看这一节

  ★ 一句话：手机用「书签/桌面图标」打开，电脑用「浏览器网址 或 双击文件」打开。

  ── 手机上（推荐，队友也用这个）──────────────────────

   ① 第一次拿到网址：先发给自己的微信（发给「文件传输助手」），
      在微信里点开链接 → 右上角 ··· → 「在浏览器打开」。
      （微信里直接看有时显示不全，用手机自带浏览器最稳。）

   ② 存成书签 / 桌面图标，以后一点就进：
        · 安卓（Chrome/Edge/夸克等）：菜单 ⋮ 或 ≡ → 「添加到主屏幕」或「收藏」
        · iPhone（Safari）：底部分享按钮 → 「添加到主屏幕」
      存完之后：不用再输网址、不用开 VPN、不用填令牌。

   ③ 两个入口，别弄混：
        展示版（发群里给全队/外面看，只能看不能改）
            https://zl4639574-bit.github.io/maitian-running/
        队长版（自己改数据、同步）
            https://zl4639574-bit.github.io/maitian-running/captain/
      队长版建议用【六】里生成的那条「专用链接」来存书签 —— 打开就自动带权限，
      不用再填令牌。

  ── 电脑上（三种，挑一种就行）────────────────────────

   ① 最省事 —— 双击文件看（不联网也能看，适合给来办公室的人看）
        E:\Desktop\麦田\麦田守望数据中心\index.html          ← 展示版
        E:\Desktop\麦田\麦田守望数据中心\captain\index.html  ← 队长版
      ⚠ 这样打开时，「生成专用链接 / 从线上拉取」这类要联网的功能会受限，
        界面上会有提示。要改数据并同步，请用第 ② 种。

   ② 推荐 —— 浏览器打开线上网址（和手机看到的完全一样，能同步）
        展示版 https://zl4639574-bit.github.io/maitian-running/
        队长版 https://zl4639574-bit.github.io/maitian-running/captain/
        按 Ctrl+D 把两条都存成书签，以后点书签进。

   ③ 看说明书 —— 双击 使用说明.txt（就是本文件）
        线上版（手机上也能看）：https://zl4639574-bit.github.io/maitian-running/guide.txt

   改完原始 Excel 要刷新线上数据：双击 更新并上传.bat（见【七】）。

  ── 打不开怎么办 ───────────────────────────────

   · 电脑上「所有」网页都打不开、一直转圈：
     多半是 Clash 关了但 Windows 系统代理还开着。双击
        E:\Desktop\麦田\系统代理_关闭（网页打不开就用它）.bat
     再刷新页面即可。（要上 GitHub 建令牌时，双击旁边那个「打开」的，用完再双击「关闭」。）

   · 手机打不开：确认是在浏览器里打开的（不是微信内置窗口）；
     确认手机没开 VPN/代理；WiFi 不行就换流量再试一次。

   · 看到的是旧内容：电脑按 Ctrl+F5 强制刷新；手机下拉刷新或关掉标签页重开。

   · 队长版打开后「数据管理」是空的 / 同步提示令牌没填：
     说明这台设备还没存过令牌。用【六】的专用链接打开一次即可（之后一直有效）。

【二】队员的成绩怎么进榜

  现在是队长统一录入（队员只负责把成绩发给队长）：

  方式 1：手动录一条
     上传成绩 → 选项目（5000米 / 3000米 / 10000米 / 半马 / 全马 / 其他）
     → 填姓名、成绩（18:35、1:23:22、18'35"、18.5 都能认）、日期、名次、赛事
     → 点「添加到我的成绩」

  方式 2：批量导入（推荐，最省事）
     上传成绩 → 把 Excel / CSV 拖进虚线框（也可以用手机点虚线框选文件，
     微信里收到的成绩表也能选）→ 系统自动猜表头行、姓名列、成绩列
     → 可以手动改 → 下面有预览 → 点「导入这 N 行」
     DNS、空值、空行会自动跳过，并告诉你跳过了几条。

  导入或录入之后，成绩先存在本机（页面会显示「本机有 N 条成绩还没上线」）。
   点「上传成绩」页里的按钮「发布并同步到线上」，一键就上线，全队立刻能看到。
   想做成「某场比赛一张榜」（而不是自由成绩），去「数据管理 → 比赛成绩」把它们
   并进那场比赛的榜单再同步。同步面板里也会提示「N 条还没发布」并给一键按钮。


【三】比赛成绩（一次测速 / 一场比赛 = 一张榜）

  成绩榜顶部有一排胶囊：「个人最好成绩」+ 每一场比赛各一张榜。
    · 个人最好成绩：把所有比赛合起来，每人每项只留最快的一次，按项目分组，自动算配速
    · 点某场比赛：看这场比赛当天的原始名次榜

  队长在 数据管理 → 比赛成绩 里可以：
    · 新建一场比赛（名称 / 日期 / 主要项目 / 备注）
    · 往某场比赛里录一条成绩，或把「上传成绩」里的几条一次并入
    · 删掉某条成绩，或删掉整场比赛
  原始资料里已有的比赛都在里面，队员和访客只能看，不能改。


【四】照片

  数据管理 → 照片：选相册（或新建相册）→ 选照片（可多选，浏览器自动压缩到长边 1500px）
  照片墙按「一个赛事一个相册」展示，点进去看整个相册，点图放大、左右翻页。


【五】队伍信息 / 荣誉 / 优秀队员 / 队员名册

  · 单独添加个人最好成绩（不用编一场比赛）：
    数据管理 → 队员名册 → 「＋ 单独添加个人最好成绩」，
    填 姓名 / 项目（半马、全马、10 公里、3000 米…）/ 成绩（1:23:29 或 17:02 都行），
    可加日期和赛事备注 → 点「添加这条成绩」→ 再点「同步我的修改到线上」。
    · 会出现在「个人最好成绩」榜（只统计正式队员）和该队员的名册卡片上。
    · 批量导入：一行一条「姓名,项目,成绩[,日期,备注]」，点「解析并预览」确认后入库
      （可以从 Excel 直接复制粘贴）。
    · 删除：在「已录入的个人最好成绩」列表里点那条后面的 ✕（线上已上线的也能删），删完点同步。
    · 名册卡片按 5000 米 / 3000 米 / 10000 米 / 半马 / 全马 的顺序显示，最多 4 条。

  · 完善队员信息（当初没填全的，在这里补）：
    数据管理 → 队员名册 → 「＋ 完善队员信息」。
    · 上面会写「名册现在 N 人，其中 M 人信息不全（缺性别 X 人）」；
    · 点「列出信息不全的 M 人」→ 表格里直接补 性别 / 学院 / 专业 / 年级 → 点「保存这些修改」
      （也可以点「列出名册全部 N 人」挨个核对）；
    · 批量补全：一行一条「姓名,性别,学院,专业,年级」，不补的列空着就行
      （也可以带表头，会自动按列名认列；从 Excel 复制粘贴即可）→「解析并预览」→ 确认；
    · 预览里如果某人显示「不在名册里」，说明名字对不上，不会被写入；
    · 补完点「同步我的修改到线上」发布。
    · 名册列表（下方每个人那行）现在也能直接改性别了。

  数据管理里对应分区，改完记得同步：
    队伍信息 —— 队名、副标题、口号、成立日期、简介、官方媒体、队伍活动
    荣誉     —— 历年战绩，一条条加减改
    优秀队员 —— 「荣誉与资料」页的优秀队员板块（默认空着不显示，想放谁再放谁）
    队员名册 —— 改学院/专业/年级/身份；把某人从公开名册移除（会进「已移除」，点 ↺ 可恢复）
                ＋ 添加新队员：填姓名/性别/学院/专业/年级/身份（正式·预备），一个一个加
                ＋ 批量添加队员：从 Excel 复制几行直接粘进去（列顺序：姓名 学院 专业 年级 性别 身份，
                  有表头也能自动认列），或者选一个 xlsx / csv 文件 → 点「解析并预览」
                  → 检查无误后点「把这 N 人加入名册」。重名和不规范的姓名会自动跳过并告诉你。
                加完之后都要去「同步」点一次「同步我的修改到线上」，线上名册才会更新。
    自由成绩 —— 不属于任何一场比赛的单独成绩


【六】同步到线上（第一次设置三步，以后不用管）

  打开队长版 → 数据管理 → 同步。

  【第一次】
   ① 点「一键打开建令牌页面（权限已勾好）」
      在打开的 GitHub 页面里：有效期选 No expiration（永久）→ 点最下面 Generate token
      → 复制那串 ghp_...（这一步需要开一下 VPN，因为要访问 github.com）
   ② 把 ghp_... 粘到上面「访问令牌」框 → 点「保存设置」
      顶部状态会变成「✅ 已配好令牌，可以同步」
   ③ 点「生成我的专用链接」→ 复制那条链接 → 存到手机书签（或微信发给自己）

  用户名 / 仓库名 / 分支已经填好了，不用动（程序会自动跟 GitHub 核对分支名）。

  【以后每天怎么用】
   · 电脑上：同一个浏览器，改完直接点「同步我的修改到线上」
   · 手机上：点书签打开 → 改数据 → 点同步。不用碰令牌、不用开 VPN
   · 约 1 分钟后展示版和队长版都更新；页面底部「数据更新于 …」的时间会变

  【换届：交给下一任队长】
   把那条专用链接发给他就行 —— 他打开就能改数据、能同步，
   不用建账号、不用弄令牌、不用开 VPN。
   链接等于管理钥匙，存好、别发群里；想作废就在 GitHub 里删掉那个令牌，重新生成一条链接。

  【可能碰到】
   · 「同步我的修改到线上」是灰的：正常，这会儿没有待同步的改动
   · 401 / 403：令牌没复制全，或建令牌时忘了勾 repo 权限
   · 手机同步失败：手机连不上 api.github.com（网络问题），换电脑同步一次即可
   · 只有建令牌那一步需要 VPN，平时同步不需要

【七】队里资料更新了怎么办（改了原始 Excel 之后）

  在电脑上双击：E:\Desktop\麦田\麦田守望数据中心\更新并上传.bat

  它会自动：① 读 E:\Desktop\麦田 里的 Excel/Word → 重生成 data/team-data.js
            ② 重新压缩照片 → images/
            ③ 记录改动  ④ 上传到 GitHub

  等 1 分钟刷新网页就是新数据。若第 4 步提示「上传失败」，开一下 VPN 再双击一次即可。

  只想更新本机、不上传：双击「更新数据.bat」。
  新的比赛/测速表也可以不写代码：用队长版「新建比赛 + 导入成绩」。

【十一】别人也能改数据吗（多个队长一起维护）

  可以，但要给"写入权"——两种给法：
    · 让他用自己的 GitHub 账号建一个精细令牌（只勾 maitian-running，Contents 读写），
      这样仓库提交记录里能看出是谁改的，你也能随时单独撤销他。
      详细步骤：见同目录「给别人用_开通说明.txt」，手机可直接打开
      https://zl4639574-bit.github.io/maitian-running/other-captains.txt
    · 或者你把队长版的「专用链接」发给他（最省事，但等于把写入权交给他，别发大群）。

  提醒：两个人同时改同一块数据时，后保存的会覆盖先保存的；
        批量修改（改身份、导入成绩）尽量一个人做完再让另一个人动。

【十二】展示版会自己变最新（实时更新）

  · 展示版每 30 秒自动检查一次线上数据：队长一同步，别人已经开着的页面会在
    半分钟内自己更新，并弹一句「数据已更新 · 09-15 08:12」。
  · 页头显示「数据更新于 xx-xx xx:xx」，就是最近一次同步的时间。
  · 总览的「最近一次测速 / 比赛」= 所有场次里日期最新的一场，**包括队长在线上新加的
    比赛/测速**；如果那次成绩没写名次，就按成绩快慢排前 5。
  · 想立刻看最新：下拉刷新即可（手机上）；页面切到后台时不会自动查，省流量。

【十三】整场成绩单（含非队员、外校选手）怎么导进来
════════════════════════════════════════════════════════════════════

  场景：一次比赛或测速有一份完整成绩单（比如计时公司发来的表），里面既有队员也有非队员。

  做法：队长版 →「上传成绩」→「② 批量导入 Excel / CSV」→ 把文件拖进去（手机点一下选文件）：
    · 确认「姓名列 / 成绩列 / 名次列 / 性别列 / 学院列」挑得对不对 → 点「导入这 N 行」；
    · 预览里会标出每个人是「队员」还是「非队员」：非队员照样导入，
      但只出现在这场比赛的榜上，不会进名册、也不会进个人最好成绩榜；
    · 成绩能认这些写法：17:35、1:23:29、18'35"、18.5（分钟）、
      Excel 里存成时间格式的（单元格显示 17:35，实际是 0.7326）、直接写秒数的（1022 = 17:02）；
    · 姓名支持 2~14 个字符：中文、少数民族名里的「·」、拼音或英文名，
      表里名字后面带的括号备注（如「张三(3班)」）会自动去掉；
    · CSV 表就算是从微信转出来的（GBK 编码）也不会乱码。

  然后做成一张榜：数据管理 → 比赛成绩 → 新建一场比赛
    → 点「把本机录入的成绩并进这场比赛」→ 同步。
    · 榜头会写「共 N 条记录（含 M 条非队员成绩）」，非队员名字旁边有一个灰色「非队员」小标；
    · 名次按成绩快慢排；个人最好成绩榜仍然只统计正式队员。

  想让他们以后进正式名单：数据管理 → 队员名册 → 添加新队员 / 批量添加队员 → 同步即可（成绩不受影响）。
