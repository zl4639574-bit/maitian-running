【二】队员怎么上传成绩（队员版）

  1. 手机打开队员版网址
  2. 点底部/顶部的「上传成绩」
  3. 先点一下是什么项目：5000米 / 3000米 / 10000米 / 半马 / 全马 / 其他
     （半马和全马是单独留的入口，跑完马拉松直接点它）
  4. 填：姓名、成绩、日期、名次（可空）、赛事名称（可空）
     成绩怎么写字都行：18:35 、 1:23:22 、 18'35" 、 18.5（分钟）
  5. 点「添加到我的成绩」
  6. 录完立刻能在「成绩榜 → 个人最好成绩」里看到自己，带一个「本机」小标

  注意：队员自己录的成绩只存在他自己手机浏览器里，别人看不见。
        要进全队的榜，点「复制成文本」，把内容发给队长；
        或者告诉队长，队长在队长版里录进去 / 用表格导入。


【三】队长怎么用（队长版）

  ① 批量导入成绩
     上传成绩 → 把 Excel / CSV 拖进去（手机上点虚线框就能选文件，
     微信里收到的成绩表也能选）→ 系统自动猜表头在第几行、哪列是姓名、哪列是成绩
     → 可以手动改 → 下面有预览 → 点「导入这 N 行」
     DNS、缺、空行会自动跳过，并告诉你跳过了几条。

  ② 把成绩归到某场比赛
     数据管理 → 比赛成绩 → 先选一场比赛 → 点「把『上传成绩』里的 N 条并入」
     也可以：新建一场比赛、往这场比赛里一条条录、点每行右边的「删」删掉某条成绩。

  ③ 传照片
     数据管理 → 照片 → 选相册（或新建相册）→ 选照片（可多选）
     浏览器会自动压缩到长边 1500px 再传，不占空间。

  ④ 改队伍信息 / 荣誉 / 名册
     数据管理里对应分区：
       队伍信息 —— 队名、副标题、口号、成立日期、简介、官方媒体、队伍活动
       荣誉     —— 一条条加减改
       队员名册 —— 改学院/专业/年级/身份，也可以把某人从公开名册里删掉（能恢复）
       自由成绩 —— 单独发布的成绩（不属于某场比赛的）

  ⑤ 同步到线上（最关键的一步）
     数据管理 → 同步，第一次要填三样东西：

       GitHub 用户名：zl4639574-bit
       仓库名：       maitian-running
       分支：         master

       访问令牌怎么弄：
         GitHub 网页 → 右上角头像 → Settings → 左下 Developer settings
         → Personal access tokens → Fine-grained tokens → Generate new token
         → Repository access 选 Only select repositories → 勾 maitian-running
         → Permissions 里找 Contents，设为 Read and write
         → Generate token → 复制那串 github_pat_... 粘贴进来
         → 点「保存设置」

     以后每次改完东西，最后点一下「同步我的修改到线上」，
     约 1 分钟后展示版、队员版、队长版全部更新。

  注意：
   · 令牌只存在你这台设备的浏览器里，不会写进网页，别人看不到。
   · 换设备（比如队长用自己手机）时，在那台设备上再填一次用户名/仓库/令牌就行，
     不需要传任何文件。
   · 如果手机同步失败，一般是手机连不上 api.github.com（不是密码问题），
     换电脑同步一次即可。
   · 「丢弃本机修改」= 放弃还没同步出去的改动，已同步到线上的不受影响。


【四】队里资料更新了怎么办（改 Excel 之后）

  在电脑上双击：E:\Desktop\麦田\麦田守望数据中心\更新数据.bat

  它会做两件事：
    1. 读 E:\Desktop\麦田 里的 Excel / Word，重新生成 data/team-data.js
    2. 重新压缩照片，生成 images/

  改完刷新网页就看到新的了（网页的数据是带时间戳加载的，不会读到旧缓存）。

  新的比赛/测速表有两种接法：
    A. 用队长版「新建比赛 + 导入成绩」——不用动代码
    B. 在 提取数据.py 里照着 ds_track(...) / ds_gaobai(...) 加一行指向新文件


【五】数据口径（哪些数字要留意）

  · 冬训营测速：原表没写距离，按性别推定（男 5000 米 / 女 3000 米）
  · 高百总决赛测速 16 公里、高百分站赛前测速 4 公里：按原表配速反推的
  · 2022.10 的 10 公里测速、2022.12 冬训营测速：年份按文件时间推断
  · 队员名册只保留标记为「正式」和「预备」的 74 人
    （其余 99 个历史名字来自队服表/高百名单/冬训营名单，已按需求隐藏）
  · 还没纳入：校运会成绩册（2021—2024，老 .doc 格式）、4—7 月跑量考勤、361° 月报


【六】隐私

  · 网页里不含学号和手机号（原始表格里有，提取时已经丢掉）
  · 页面加了 noindex，搜索引擎不会收录
  · 但名册里有真实姓名、学院、成绩和照片 —— 链接发到群里，
    等于对拿到链接的人公开。想更保守，可以：只显示现役队员，或姓名改成「姓+名首字」，
    告诉我就行。

【八】我自己怎么更新数据（三种方式，按省事程度排）

  方式 1：用队长版网页改（最省事，不需要电脑）
     手机/电脑打开队长版 → 数据管理，
     改队伍信息、荣誉、名册，或用「比赛成绩」新建比赛、导入成绩、录成绩，
     或用「照片」传照片 → 最后点「同步我的修改到线上」→ 约 1 分钟三版全更新。
     （第一次要先在「同步」里填 GitHub 用户名 / 仓库名 / 令牌，见【三】⑤）

  方式 2：改了原始 Excel 之后（在电脑上，双击一次就行）
     1. 把新的成绩表放进 E:\Desktop\麦田\ 里（放哪都行，脚本按文件名找）
     2. 双击 E:\Desktop\麦田\麦田守望数据中心\更新并上传.bat
        它会自动做四件事：
          ① 读 Excel/Word → 重新生成 data/team-data.js
          ② 重新压缩照片 → images/
          ③ 记录改动
          ④ 上传到 GitHub
     3. 等 1 分钟，三个网址就是新数据
     如果第 4 步提示「上传失败」，开一下 VPN 再双击一次即可。

  方式 3：直接在 GitHub 网页上改（临时小修改）
     打开 https://github.com/zl4639574-bit/maitian-running
     → 找到文件（比如 data/team-data.js 或 guide.txt）→ 点铅笔图标改 → Commit changes。
     适合改个小数字、改说明文字；大批量成绩还是用方式 1 或 2。

  怎么知道更新成功没有？
     打开网址 → 拉到页面最底部，会显示「数据更新于 2026-09-14 14:57」这样的时间戳，
     时间变了就是更新成功了。手机浏览器记得下拉刷新一下。
