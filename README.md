## 两个版本的区别

- **展示版**：只有「总览 / 成绩榜 / 队员名册 / 照片墙 / 荣誉与资料」，没有管理入口，发群里、发朋友圈都安全。
- **队长版**：多出「上传成绩 / 数据管理」，能改名册、录成绩、传照片、单独加个人最好成绩、完善队员信息；改完点「同步我的修改到线上」即上线（GitHub Pages 约 30–90 秒生效，展示版每 30 秒自动检查更新）。

## 数据存在哪里

- **线上（权威）**：本仓库 —— `data/team-data.js`（名册/成绩/队伍信息）、`data/overrides.js`（线上改动）、`images/`（照片）。
  每次「同步」= 一次提交，历史可回滚。
- **本机**：一份和线上完全一致的工作副本；浏览器里可能还有"还没同步的改动"（点同步后清空）。
- **原始资料**（Excel、原图）只在本机，请自行备份。

## 隐私

学号、联系方式**不上网页**；只公开 姓名 / 年级 / 学院 / 专业 / 身份 / 成绩 / 照片。

> ⚠️ 队长版的「专用链接」里带写入令牌（`.../captain/#t=...`），只发给信任的队长，
> **不要发群、不要写进文件、不要截图**。令牌只存在各人自己的浏览器里。
