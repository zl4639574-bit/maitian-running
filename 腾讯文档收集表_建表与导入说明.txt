麦田守望 · 腾讯文档收集表：怎么建、怎么导进网页
（零成本方案：不用云服务器、不用令牌、永久免费；队员点开链接填完提交即可）

一、建两张收集表（腾讯文档 → 新建 → 「收集表」）
────────────────────────────────────────────────────────────────
表① 队员资料收集（一行一个人；列名请照抄，导入时靠列名认）
   1. 姓名        （填空题 · 必填）
   2. 性别        （单选题：男 / 女）
   3. 学院        （填空题）
   4. 专业        （填空题）
   5. 年级        （填空题，例如 2023）
   6. 800米（没有填无）    ← 名字照抄，括号里这句也留着，队员才知道填什么
   7. 1500米（没有填无）
   8. 3000米（没有填无）
   9. 5000米（没有填无）
   10. 10000米（没有填无）
   11. 半马（没有填无）
   12. 全马（没有填无）
   设置建议：允许"提交后可修改"（队员填错能自己改）；不用强制登录；可写一句提交后提示：
             「已提交，谢谢！队长会统一导入到队里的网页。」

表② 成绩上报收集（一行一次成绩，用于比赛/测速）
   1. 姓名  2. 项目（单选：5000米 / 3000米 / 10000米 / 半马 / 全马 / 其他）
   3. 成绩（例如 18:35 或 1:23:29）  4. 日期（例如 2026.09.15）
   5. 赛事名称（例如 2026杨凌马拉松；能和队里已有的赛事名一样最好）

二、队员怎么用
   你把收集表链接发队群 → 队员点开 → 填 → 提交。不用登录、不用加你微信、不用装 App。

三、你（队长）怎么导进网页
   ① 队员资料表：
      腾讯文档 → 打开收集表 →「查看收集结果」→ 导出为 Excel
      → 队长版 →「数据管理」→「队员名册」→「＋ 导入收集表（Excel/CSV，一行一个人）」
      → 选刚导出的文件 → 看预览（会列出每人有哪些成绩、谁不在名册）→「全部导入」
      → 再点「同步我的修改到线上」，展示版名册就更新了。
   ② 成绩表：
      导出 Excel → 队长版 →「上传成绩」→「② 批量导入 Excel / CSV」→ 把文件拖进去
      → 确认「姓名 / 成绩 / 日期 / 赛事」几列认对了 →「导入这些行」
      → 数据管理 →「比赛成绩」→ 新建一场（或用已有的那场）→「把本机录入的成绩并进这场比赛」
      →「同步我的修改到线上」。

四、为什么能自动认列
   · 列名里含「姓名 / 性别 / 学院 / 专业 / 年级 / 800米 / 1500米 … / 半马 / 全马」就自动对应；
   · 「提交时间」「填写人」这些收集表自带列会自动忽略；
   · 没有的距离填「无」→ 不写进成绩榜（不会出现"0:00"这种脏数据）；
   · 名册里没有的人也能导入（会新增一位），但成绩只进当场榜、不进个人最好成绩榜的规则不变。
   · CSV/Excel 都行；微信转出来的 GBK 编码 CSV 也不会乱码。

五、几个要注意的
   · 同一个人重复提交会有多行：导入是"后导入的覆盖先导入的"，所以最好让队员自己改原来那条；
   · 成绩表导入是"新增"，别把同一份文件导两次（导两次会多一份成绩）；
   · 收集表有链接就能填，建议只发队群；导入前一定看一眼预览，乱填的行会被跳过（姓名看不懂/成绩认不出）；
   · 资料表导入不会覆盖队员已上传的头像；照片仍然走收集页（report 页）的「完善我的资料 → 照片」
     或队员直接把照片发你。
